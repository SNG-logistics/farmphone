1. รู้จักระบบและขอบเขตการใช้งาน

FARM PHONE AI OFFICE เป็นศูนย์กลางสำหรับดูสถานะโทรศัพท์ จัดเก็บข้อมูลช่องและคลิป สร้างงานโพสต์ ติดตามผล และรับแจ้งเตือนจากอุปกรณ์หลายเครื่องในหน้าจอเดียว

ลำดับการทำงานหลัก

เตรียมโทรศัพท์ → ผูกช่อง → เพิ่มคลิป → สร้างแคมเปญ → ตรวจความพร้อม → เริ่มงาน → ตรวจผล → เก็บรายงาน

บทบาทผู้ใช้งาน

บทบาทหน้าที่ทั่วไป
Owner / Adminจัดการผู้ใช้ สิทธิ์ เครื่อง ช่อง การตั้งค่า และตรวจรายงานทั้งหมด
Managerอนุมัติคลิป วางแผนแคมเปญ และตรวจผลรวม
Operatorเพิ่มคลิป ตรวจเครื่อง เริ่มหรือหยุดงาน และแก้ปัญหาเบื้องต้น
Viewerดู Dashboard สถานะ และรายงานโดยไม่แก้ข้อมูล

2. เริ่มต้นใช้งานและเข้าสู่ระบบ

  1. รับ URL ระบบ ชื่อผู้ใช้ รหัสผ่าน และช่องทางติดต่อผู้ดูแลจากผู้ให้บริการ
  2. เปิดระบบด้วย Chrome หรือ Edge เวอร์ชันล่าสุดบนคอมพิวเตอร์
  3. กรอกอีเมลและรหัสผ่าน แล้วกด เข้าสู่ระบบ
  4. ตรวจชื่อองค์กรหรือแพ็กเกจด้านบนของหน้าจอให้ถูกต้อง
  5. เปลี่ยนรหัสผ่านเมื่อเข้าใช้งานครั้งแรก และไม่ส่งรหัสผ่านในกลุ่มแชต
เข้าสู่ระบบไม่ได้: ตรวจภาษาแป้นพิมพ์ ปุ่ม Caps Lock และ URL ก่อน หากลองหลายครั้งแล้วยังไม่ได้ให้หยุดและติดต่อผู้ดูแล เพื่อป้องกันบัญชีถูกล็อก

3. หน้า Dashboard และสถานะสำคัญ

สถานะความหมายสิ่งที่ควรทำ
ONLINE / READYพร้อมรับงานใช้งานได้ตามปกติ
BUSY / RUNNINGกำลังทำงานอย่าควบคุมเครื่องด้วยมือ
WARNINGมีเงื่อนไขเสี่ยง เช่น แบตต่ำตรวจรายละเอียดก่อนเริ่มงาน
OFFLINE / ERRORไม่เชื่อมต่อหรือเกิดข้อผิดพลาดหยุดส่งงานและแก้สาเหตุก่อน
AUTH REQUIREDช่องต้องเข้าสู่ระบบหรือยืนยันตัวตนให้ผู้มีสิทธิ์จัดการบนโทรศัพท์

ก่อนเริ่มงานทุกครั้ง ให้ดูจำนวนเครื่องออนไลน์ งานที่กำลังทำ งานล้มเหลว แบตเตอรี่ และข้อความเตือนล่าสุด หากข้อมูลไม่อัปเดตให้รีเฟรชหน้าเว็บหนึ่งครั้ง

4. จัดการโทรศัพท์

เพิ่มและเตรียมเครื่อง

  1. เปิด Developer options และ USB debugging ตามคำแนะนำของผู้ให้บริการ
  2. ติดตั้งแอปโซเชียลที่ได้รับอนุญาต และอัปเดตเป็นเวอร์ชันที่ระบบรองรับ
  3. เชื่อม Wi-Fi ที่เสถียร เสียบชาร์จ และควรมีแบตเตอรี่มากกว่า 50%
  4. เปิดเมนู Devices แล้วตรวจว่าเครื่องปรากฏเป็น ONLINE
  5. ตั้งชื่อที่จำง่าย เช่น PHONE-001 และจัดเข้ากลุ่มที่ถูกต้อง

เกณฑ์พร้อมทำงาน

  • สถานะ ONLINE และมี heartbeat ล่าสุด
  • แบตเตอรี่เกิน 50% หรือเสียบชาร์จ
  • พื้นที่ว่างพอสำหรับไฟล์คลิป
  • หน้าจอไม่ล็อกระหว่างทำงาน
  • ไม่มี popup, update หรือการขอสิทธิ์ค้างอยู่
  • เปิดบัญชีเป้าหมายตรงกับช่องที่ผูกในระบบ
เมื่อเครื่องแสดง BUSY ห้ามจับหน้าจอ เปิดแอปอื่น ถอดสาย หรือสลับบัญชี เพราะอาจทำให้งานลงผิดช่องหรือล้มเหลว

5. จัดการบัญชีหรือช่อง

  1. เข้าเมนู Accounts แล้วเลือก เพิ่มบัญชี
  2. เลือกแพลตฟอร์ม กรอก Username และตั้งชื่อเรียก เช่น “ช่อง 1”
  3. เลือกโทรศัพท์ที่ล็อกอินบัญชีนี้อยู่จริง
  4. บันทึก แล้วตรวจสถานะเป็น ACTIVE และการยืนยันตัวตนเป็นปกติ
  5. เปิดแอปบนโทรศัพท์และตรวจหน้าโปรไฟล์ว่าตรงกับ Username ในระบบ

เมื่อเปลี่ยนรหัสผ่านหรือออกจากระบบ

หยุดแคมเปญของช่องนั้นก่อน เข้าสู่ระบบใหม่บนเครื่องเดิม ตรวจว่าไม่มี OTP หรือ CAPTCHA ค้าง แล้วจึงเปลี่ยนสถานะช่องกลับเป็น ACTIVE

แนะนำให้หนึ่งช่องมีเครื่องหลักที่ระบุชัดเจน และตั้งชื่อเครื่องกับช่องให้สัมพันธ์กัน เช่น PHONE-001 ↔ CHANNEL-001

6. จัดการคลิปและเนื้อหา

  1. เข้าเมนู Content และเลือก เพิ่มเนื้อหา
  2. เลือกไฟล์วิดีโอ แล้วรอจนแถบอัปโหลดครบ 100%
  3. กรอกชื่อคลิป Caption, Hashtags และ Tags ให้ครบ
  4. ตรวจภาพตัวอย่าง ความยาว ความละเอียด และเสียง
  5. ตรวจคำต้องห้าม ลิขสิทธิ์ ข้อมูลส่วนตัว และนโยบายแพลตฟอร์ม
  6. เมื่อพร้อมใช้งาน ให้สถานะคลิปเป็น READY

รูปแบบแนะนำ

รายการคำแนะนำ
ไฟล์MP4, H.264, เสียง AAC
คลิปแนวตั้ง1080 × 1920 พิกเซล
ชื่อไฟล์ใช้ตัวอักษรอังกฤษ ตัวเลข ขีดกลาง เช่น CLIP-001.mp4
Captionตรวจสะกด ลิงก์ โปรโมชั่น และวันหมดอายุ
Hashtagsใช้เฉพาะคำที่เกี่ยวข้องและไม่มากเกินไป

7. สร้างแคมเปญและสั่งงาน

  1. เข้าเมนู Campaigns แล้วเลือก สร้างแคมเปญ
  2. ตั้งชื่อที่ค้นง่าย เช่น วันที่ + ชื่อชุดคลิป + กลุ่มช่อง
  3. เลือกคลิป บัญชีเป้าหมาย และกลุ่มโทรศัพท์ให้ถูกต้อง
  4. กำหนดเวลา จำนวนงานต่อวัน ลำดับ และจำนวนครั้งที่อนุญาตให้ลองใหม่
  5. บันทึกเป็น DRAFT และตรวจสรุปอีกครั้ง
  6. เมื่อทุกอย่างพร้อม เปลี่ยนเป็น READY แล้วกดเริ่มงาน

จุดตรวจอนุมัติก่อนเริ่ม

  • จำนวนคลิปและจำนวนช่องตรงตามใบงาน
  • คลิปทุกไฟล์เป็น READY
  • ช่องทุกช่องเป็น ACTIVE
  • เครื่องทุกเครื่องเป็น ONLINE และไม่มีงานซ้อน
  • เวลาโพสต์และเขตเวลาถูกต้อง
  • Caption และ Hashtags ผ่านการอนุมัติ
เริ่มจากงานน้อยก่อน: แคมเปญใหม่ควรทดลอง 1 คลิป 1 ช่อง 1 เครื่อง แล้วตรวจผลจริงก่อนขยายจำนวนงาน

8. ตัวอย่าง: คลิป 1 ลงช่อง 1

1 เปิด Devices และตรวจ PHONE-001 เป็น ONLINE แบตเตอรี่เพียงพอ และไม่มีงานค้าง

2 เปิด Accounts ตรวจ “ช่อง 1” เป็น ACTIVE และผูกกับ PHONE-001

3 เปิดแอปบนโทรศัพท์ ตรวจหน้าโปรไฟล์ว่าคือช่อง 1 จริง แล้วกลับหน้า Home

4 เปิด Content เลือก “คลิป 1” ดูวิดีโอและตรวจ Caption จนจบ

5 สร้าง Campaign ชื่อ “คลิป 1 ลงช่อง 1” เลือกคลิป 1 ช่อง 1 และ PHONE-001

6 เลือกลงทันทีหรือกำหนดเวลา ตรวจสรุป แล้วเปลี่ยนสถานะเป็น READY

7 กดเริ่มงาน จากนั้นห้ามใช้งานโทรศัพท์จนกว่างานจะจบ

8 ดูสถานะตามลำดับ CREATED → RUNNING → VERIFYING → SUCCESS

9 เปิดโพสต์จริง ตรวจคลิป เสียง Caption, Hashtags และการมองเห็น

10 บันทึกลิงก์โพสต์ เวลา และภาพหลักฐาน แล้วปิดงานเป็น COMPLETED

ถือว่างานสำเร็จเมื่อ: โพสต์ปรากฏในช่องเป้าหมาย เปิดเล่นได้ ข้อมูลถูกต้อง และระบบเก็บหลักฐานครบ ไม่ใช่เพียงแค่กดปุ่มโพสต์แล้ว

9. ติดตามงานและตรวจผล

สถานะงานคำอธิบาย
CREATED / QUEUEDสร้างงานแล้วและกำลังรอคิว
ASSIGNEDเลือกโทรศัพท์และช่องแล้ว
RUNNINGโทรศัพท์กำลังทำขั้นตอนโพสต์
VERIFYINGกำลังตรวจว่าโพสต์สำเร็จจริง
SUCCESSโพสต์และตรวจหลักฐานสำเร็จ
FAILEDงานไม่สำเร็จ ต้องเปิดดู Error และหลักฐาน
CANCELLEDงานถูกยกเลิกโดยผู้ใช้หรือระบบ

หลังงานจบ ควรตรวจ Post URL, Post ID, ช่อง, เครื่อง, เวลาที่โพสต์, Caption และ Screenshot หากข้อมูลใดหาย ให้เปิด Ticket ก่อนเริ่มงานชุดใหญ่ต่อไป

10. แก้ปัญหาเบื้องต้น

อาการวิธีตรวจและแก้
เครื่อง OFFLINEตรวจไฟ สาย USB/Wi-Fi เปิดหน้าจอ แล้วรอ heartbeat; หากยังไม่กลับมาให้ติดต่อผู้ดูแล
แบตเตอรี่ต่ำหยุดส่งงาน เสียบชาร์จ และรอให้เกินระดับที่กำหนด
ช่อง AUTH REQUIREDหยุดแคมเปญ เข้าสู่ระบบบนเครื่อง ตรวจ OTP/CAPTCHA แล้วทดสอบด้วยงานเดียว
อัปโหลดค้างอย่ากดซ้ำทันที ตรวจอินเทอร์เน็ตและสถานะงาน เพื่อป้องกันโพสต์ซ้ำ
FAILEDอ่าน Error เปิด Screenshot ตรวจช่องและเครื่อง แล้วลองใหม่เฉพาะเมื่อสาเหตุถูกแก้แล้ว
โพสต์ผิดช่องหยุดทุกงานของเครื่องนั้น บันทึกหลักฐาน แจ้ง Admin และตรวจการผูกช่องใหม่
CAPTCHA / OTPห้ามให้ระบบกดต่อ ให้ผู้มีสิทธิ์ดำเนินการด้วยตนเองและบันทึกเหตุการณ์

ข้อมูลที่ต้องส่งเมื่อแจ้งปัญหา

  • ชื่อองค์กรและชื่อผู้ใช้งาน
  • Campaign ID และ Job ID
  • ชื่อช่องและรหัสโทรศัพท์
  • เวลาที่เกิดปัญหา
  • ข้อความ Error, Screenshot หรือวิดีโอหน้าจอ
  • สิ่งที่ทำไปก่อนเกิดปัญหา

11. ความปลอดภัยและข้อควรระวัง

  • ห้ามแชร์รหัสผ่าน Token, OTP หรือ Recovery Code ในแชตสาธารณะ
  • เปิดสิทธิ์ผู้ใช้เท่าที่จำเป็น และยกเลิกสิทธิ์ทันทีเมื่อพนักงานออก
  • ห้ามใช้คลิปหรือเพลงที่ไม่มีสิทธิ์ และห้ามโพสต์เนื้อหาผิดกฎหมาย
  • ปฏิบัติตามข้อกำหนดของ TikTok, YouTube, Facebook หรือแพลตฟอร์มเป้าหมาย
  • ห้ามพยายามหลบ CAPTCHA, ระบบป้องกัน หรือข้อจำกัดของแพลตฟอร์ม
  • สำรองคลิปและรายงานสำคัญตามรอบที่ผู้ให้บริการกำหนด
  • ตรวจ Audit Log เมื่อพบการแก้ข้อมูลที่ไม่ทราบที่มา

12. เช็กลิสต์ประจำวัน

ก่อนเริ่มงาน

  • เข้าสู่ระบบด้วยบัญชีของตนเอง
  • ตรวจ Dashboard และข้อความเตือน
  • เครื่องเป้าหมาย ONLINE แบตและพื้นที่เพียงพอ
  • ช่องเป้าหมาย ACTIVE และล็อกอินถูกบัญชี
  • คลิปและข้อความผ่านการอนุมัติ
  • เวลาและจำนวนงานตรงตามแผน

หลังจบงาน

  • ไม่มีงานค้างใน RUNNING หรือ VERIFYING
  • ตรวจโพสต์จริงและบันทึกลิงก์ครบ
  • ตรวจงาน FAILED และเปิด Ticket หากจำเป็น
  • ปิดหรือพักแคมเปญที่จบแล้ว
  • ตรวจเครื่องร้อน แบตต่ำ หรือพื้นที่ใกล้เต็ม
  • ออกจากระบบเมื่อใช้คอมพิวเตอร์ร่วมกับผู้อื่น
